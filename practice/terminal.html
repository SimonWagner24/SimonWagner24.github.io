Exploring the Unix Terminal

File System Navigation

cd(Change Directory)

CD navigates to a specific folder

cd .. moves you up one level to the parent directory

cd ~ instantly returns you to your home directory

ls(List)

Shows the files and folders inside your current directory.

ls -l displays a detailed "long" list showing file sizes, permissions, and modification dates.

ls -a lists all files, including hidden files (those starting with a dot).

pwd(Print Work Directory)

Displays the absolute path of the directory you are currently in.

touch [filename]

: Creates an empty file or updates the timestamp of an existing file.

mkdir [dir_name] (Make Directory)

Creates a new folder.

cp [source] [destination] (Copy)

Copy): Copies files or directories. (Use cp -r to copy folders recursively.)

mv [source] [destination] (Move/Rename)

Moves a file or folder to a new location, or renames it if the destination path is the same folder.

rm filename (Remove)

Deletes a file

rm -r [filename] deletes a folder and everything inside

rmdir [dir_name]

Deletes an empty directory

Viewing and Text Processing

cat [filename] Concatenate)

Displays the entire contents of a file directly in the terminal.

less [filename]

Opens a file in a scrollable viewer (press q to exit).

grep "[pattern]" [filename]

Searches for specific words or patterns inside a file.
